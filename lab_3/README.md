# Laboratory work 3 — Synchronized shared memory

Составить и отладить программу на языке Си, осуществляющую работу с процессами и
взаимодействие между ними в одной из двух операционных систем. В результате работы
программа (основной процесс) должен создать для решение задачи один или несколько дочерних
процессов. Взаимодействие между процессами осуществляется через системные сигналы/события
и/или через отображаемые файлы (memory-mapped files).
Необходимо обрабатывать системные ошибки, которые могут возникнуть в результате работы.

## Вариант 2.
Пользователь вводит команды вида: «число число числоendline». Далее эти числа
передаются от родительского процесса в дочерний. Дочерний процесс считает их сумму и
выводит её в файл. Числа имеют тип float. Количество чисел может быть произвольным.

## Build
```bash
make
```
## Run
``` bash
./parent.out
```
