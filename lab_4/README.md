# Лабораторная работа №4, вариант 2

## Задание

Реализовать две функции с двумя разными алгоритмами и создать две динамические библиотеки.

Функции:
- `sin_integral(a, b, e)` — вычисление интеграла sin(x) на отрезке [a, b] с шагом e.
- `prime_count(a, b)` — подсчёт простых чисел на отрезке [a, b].

Реализации:
- `libfirst.so` — метод левых прямоугольников и наивная проверка простых чисел.
- `libsecond.so` — метод трапеций и решето Эратосфена.

## Сборка

```bash
make
```

## Запуск

Первая программа (библиотека подключается при компоновке):

```bash
./program1.out
```

Вторая программа (библиотека загружается во время выполнения):

```bash
./program2.out
```

## Команды

- `1 a b e` — вычислить интеграл sin(x) на отрезке [a, b].
- `2 a b` — подсчитать количество простых чисел на отрезке [a, b].
- `0` — переключить реализацию в `program2.out`.
- `Ctrl+D` — завершить программу.

Пример ввода для `program2.out`:

```text
1 0 2 0.8
2 1 20
0
1 0 2 0.8
2 1 20
```

## Способы подключения библиотек

**Программа №1 (`program1.out`)**

Использует `libfirst.so`, подключённую на этапе компоновки. Функции вызываются напрямую по имени.

Для смены реализации необходимо перекомпоновать программу с другой библиотекой.

**Программа №2 (`program2.out`)**

Использует `dlopen()` для загрузки библиотеки, `dlsym()` для получения адресов функций и `dlclose()` для закрытия библиотеки.

Команда `0` позволяет переключаться между `libfirst.so` и `libsecond.so` без перезапуска программы.

## Очистка

```bash
make clean
```
